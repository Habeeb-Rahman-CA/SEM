Broadcasting live scores to OBS / vMix

Each stream session exposes a public JSON endpoint with the current score, team names, competition context, and live match data. Point a browser source at the overlay URL (shown per session) or fetch the JSON directly and render it in your own overlay template.

1. Public spectator portal
Share /public/streaming/<id> with viewers. They can watch the embed and see live scores without logging in.
2. Overlay JSON
Poll /public/streaming/overlay/<id> from an OBS browser source (or your own overlay page) every few seconds to pull real-time score, status, and viewer count.
3. Highlights & clips
Bookmark moments as they happen with the timestamp buttons on the Sessions tab. Highlights show up on the public portal and in the spectator player's chapter list.
